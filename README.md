# CineScope SQL — Movie Database Analytics & Insights

## Project Overview

CineScope SQL is an end-to-end movie database analytics project designed to analyze movie information, genres, directors, ratings, budgets, revenue, and profitability using SQL.

The project demonstrates database design, data cleaning, SQL analysis, advanced queries, business insights, and interactive data visualization.

## Project Objectives

* Design a structured relational movie database
* Import and clean movie data
* Perform basic and advanced SQL analysis
* Analyze movie ratings, genres, revenue, budgets, and profitability
* Generate business insights using SQL
* Build an interactive Power BI dashboard
* Maintain the project using Git and GitHub

## Technologies Used

* MySQL
* MySQL Workbench
* SQL
* Power BI
* Git
* GitHub
